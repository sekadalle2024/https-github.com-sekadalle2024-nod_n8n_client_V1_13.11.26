### Raccourci Bureau

Créez un raccourci vers :

- **Cible :** `powershell.exe`
- **Arguments :** `-NoExit -Command "cd h:\nod_n8n; .\push-github.ps1"`
- **Nom :** "Push GitHub - nod_n8n"

### Alias PowerShell

Dans votre `$PROFILE` :

```powershell

    Set-Location h:\nod_n8n
    .\push-github.ps1
}
```

Puis depuis n'importe où :

```powershell
push-nod    # Sauvegarde !
```
