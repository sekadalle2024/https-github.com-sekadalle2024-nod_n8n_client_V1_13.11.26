## 📜 Les 3 Scripts Créés

### 1. `push-to-github.ps1` - Automatique ⚡

**Fonction :**

```powershell
1. git add .
2. git commit -m "Message avec date"
3. git remote set-url origin https://github.com/...
4. git push -u origin main
```

**Utilisation :** Sauvegardes quotidiennes  
**Durée :** 30 secondes

---

### 2. `push-interactif.ps1` - Guidé 📋

**Fonction :**

```powershell
1. Vérifie Git installé
2. Affiche état du repo
3. Liste fichiers modifiés
4. Demande confirmations
5. Permet message personnalisé
6. Guide authentification
7. Push avec explications
```

**Utilisation :** Apprentissage, gros push  
**Durée :** 2-5 minutes

---

### 3. `verify-before-push.ps1` - Vérification 🔍

**Fonction :**

```powershell
1. Affiche config Git
2. Montre branche active
3. Liste fichiers modifiés
4. Vérifie fichiers sensibles
5. Affiche dernier commit
6. AUCUNE MODIFICATION (lecture seule)
```

**Utilisation :** Vérification avant push  
**Durée :** 15 secondes
