📊 Test - Tables d'Audit (Direct PostgreSQL)

🎯 Interface de Test Direct

1️⃣ Voir les tables existantes

Exécutez cette commande dans votre terminal PowerShell :

docker exec nod-local-postgres-1 psql -U nod -d nod -c "SELECT id, display_name, owner_id FROM audit_table_schemas;"

2️⃣ Voir les données d'une table

Utilisez l'ID de la table (copié ci-dessus) :

docker exec nod-local-postgres-1 psql -U nod -d nod -c "SELECT id, row_data, row_order, deleted_at FROM audit_table_data WHERE table_schema_id='a61e51b2-994e-415b-8726-a5e85e279ded' ORDER BY row_order;"

3️⃣ Voir l'historique des versions

Voir toutes les modifications enregistrées :

docker exec nod-local-postgres-1 psql -U nod -d nod -c "SELECT id, change_type, changed_by, changed_at, row_data FROM audit_data_versions ORDER BY changed_at DESC LIMIT 10;"

4️⃣ Ajouter une nouvelle ligne

Exécutez le script Node.js complet :

node test-persistence-direct.mjs

✅ Ce script crée automatiquement : 1 table + 2 lignes + 1 modification + 1 historique

5️⃣ Nettoyer les données de test

Supprimer toutes les données de test :

docker exec nod-local-postgres-1 psql -U nod -d nod -c "DELETE FROM audit_table_schemas WHERE owner_id='test_user_001';"

⚠️ Attention : supprime toutes les tables de test

💡 Pourquoi cette interface ?

L'interface précédente nécessite que le serveur Nod tourne sur http://localhost:4310. Comme il n'est pas démarré actuellement, cette interface vous permet de tester directement avec PostgreSQL.

Avantage : Vous pouvez vérifier que toutes les données sont bien persistées dans la base de données ! 🎉
